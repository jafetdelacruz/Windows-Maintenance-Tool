# Laboratorios locales

Los archivos `.wsb` son perfiles de trabajo para Windows Sandbox. Reemplaza
`C:\Path\To\Windows-Maintenance-Tool` en los perfiles por la ruta absoluta del
repositorio en tu equipo y crea las carpetas de `artifacts` que indiquen sus
montajes antes de abrirlos. Estas rutas son plantillas; no incluyen los
paquetes compilados ni los resultados de pruebas.

Ejecuta los laboratorios únicamente en Windows Sandbox con datos ficticios.
Los perfiles Sandbox pueden compartir carpetas del host, así que revisa cada
montaje antes de iniciar una sesión.
